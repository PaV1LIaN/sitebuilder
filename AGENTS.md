# Работа со стилями SiteBuilder

- Не использовать `!important` и приоритет `important` в `style.setProperty()`.
- Перед изменением найти существующее правило и исправить его в файле-владельце. Не добавлять в конец файла очередной блок переопределений или файлы `*-vN.css` / `*-fix.css`.
- Расположение стилей и порядок подключения описаны в `STYLES.md`.
- Порядок внутри компонента: базовые правила, варианты, состояния, затем адаптивность. Не повышать специфичность дублированием классов/ID.
- PHP передаёт значения настроек через CSS-переменные. Постоянные стили интерфейса находятся в CSS. JavaScript меняет классы, `hidden` и действительно динамические значения без принудительного приоритета.
- Проверять скрытые/открытые окна, выбранные элементы и размеры 1440, 768, 390 px; для анимации — также reduced motion.
- Перед завершением выполнить `npm run test:styles` и, если изменён внешний вид или состояние элемента, `npm run test:styles:browser`. Проверки используют макеты из настоящей разметки, но не заменяют проверку на портале с Bitrix.
