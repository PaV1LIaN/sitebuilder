# SiteBuilder Stage 20 — бизнес-компоненты, формы и SEO

Stage 20 устанавливается поверх Stage 19. Полный архив также содержит изменения Stage 16–19.

## Миграция

Файл:

`migrations/20260730_009_forms_and_seo.sql`

Миграция:

- добавляет `sitebuilder.page.seo_json`;
- создаёт `sitebuilder.form_submission`;
- добавляет индексы для списка заявок;
- не содержит `DROP`, `TRUNCATE` и удаления существующих данных.

Применение через интерфейс:

`/local/sitebuilder/tools/apply_stage20_migration.php`

После установки статус можно проверить на странице:

`/local/sitebuilder/deployment.php`

## SEO страниц

В инспектор страницы добавлены:

- SEO-заголовок;
- description;
- keywords;
- canonical URL;
- index/noindex;
- follow/nofollow;
- Open Graph title, description и image.

Опубликованная страница формирует соответствующие мета-теги. Для каждого сайта доступна карта сайта:

`/local/sitebuilder/s/{site-slug}/sitemap.xml`

Страницы с `noindex` в sitemap не включаются.

SEO-настройки входят в:

- историю версий страницы;
- корзину и восстановление страниц;
- шаблоны сайта;
- резервные копии и восстановление сайта.

## Формы и заявки

Новый блок `form` поддерживает поля:

- текст;
- email;
- телефон;
- многострочный текст;
- список;
- checkbox.

Доступны обязательность, placeholder и ширина поля.

Защита отправки:

- Bitrix `sessid`;
- honeypot;
- серверная валидация;
- ограничение частоты — до пяти отправок за пять минут с одного IP для одной формы;
- повторная проверка связи сайта, страницы и блока;
- форма принимается только с опубликованной страницы.

Заявки хранятся в PostgreSQL. Страница управления:

`/local/sitebuilder/forms.php?siteId=ID`

Доступ имеют Bitrix-администратор, OWNER и ADMIN сайта. Статусы:

- `new`;
- `in_progress`;
- `done`;
- `spam`.

Заявки удаляются вместе с сайтом. Retention по умолчанию — 730 дней, настройка:

`config/maintenance.php` → `form_submission_retention_days`.

## Новые компоненты

- FAQ;
- видео YouTube, Vimeo и прямые MP4/WebM/OGG;
- тарифы;
- форма;
- галерея;
- навигационный блок;
- подвал.

Навигацию и подвал можно сохранить как глобальные блоки Stage 19 и использовать на нескольких страницах.

## Ограничения

- Заявки пока только сохраняются в PostgreSQL; автоматическая email/IM-доставка не включена.
- Содержимое заявок не входит в переносимый backup сайта, чтобы не переносить персональные данные вместе с дизайном.
- Для публичной отправки пользователь должен быть авторизован в Bitrix или войти через технического гостя, как предусмотрено текущей моделью SiteBuilder.
