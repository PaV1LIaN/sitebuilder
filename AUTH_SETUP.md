# Авторизация SiteBuilder

## Что уже подключено

- `login.php` принимает обычный логин/пароль Битрикс и предоставляет кнопку гостевого входа.
- `index.php`, `editor.php`, `files.php`, `layout.php`, `menu.php`, `settings.php` и `public.php` перенаправляют неавторизованного пользователя на `/local/sitebuilder/login.php`.
- Основной API возвращает `401 AUTH_REQUIRED` и ссылку на страницу входа.
- Публичный рендер показывает только опубликованные страницы, доступные текущему пользователю по глобальной роли или `page_access`.
- Действия Диска дополнительно проверяют принадлежность файла/папки разрешённому корню.

## Настройка гостя

1. Создать отдельного активного пользователя Битрикс без группы администраторов.
2. Указать его ID в `config/auth.php` (`guest_user_id`).
3. В интерфейсе SiteBuilder назначить этому пользователю прямую роль `VIEWER` на нужные сайты.
4. Не полагаться только на роль участника группы Битрикс: компонент Диска читает прямые записи `sitebuilder.access` и коды групп Битрикс.
5. На уровне Битрикс.Диска оставить только чтение/скачивание нужного storage/root.

## Важно

Общий технический пользователь подходит только для режима чтения. Все гостевые сессии будут отображаться в аудитах Битрикс как один пользователь.
