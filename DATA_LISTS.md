# Универсальные списки: первая версия

Список — самостоятельный набор данных сайта. Блок страницы хранит ссылку на него и параметры отображения. Несколько блоков могут показывать одни записи с разными фильтрами. Функция предназначена для реестров, заявок, контактов и других структурированных данных.

## Обновление портала

Разверните файлы и примените новую миграцию `20260911_012_data_lists` через `/local/sitebuilder/deployment.php` либо CLI:

```bash
DOCUMENT_ROOT=/home/bitrix/www php /home/bitrix/www/local/sitebuilder/tools/migrate_cli.php --apply
DOCUMENT_ROOT=/home/bitrix/www php /home/bitrix/www/local/sitebuilder/tools/migrate_cli.php --status
```

Путь `/home/bitrix/www` замените на корень вашего портала. Миграция создаёт таблицы списков и записей в PostgreSQL. После обновления перезагрузите редактор страницы.

## Создание и использование

1. В редакторе страницы добавьте блок **Список** из категории данных.
2. Нажмите **Создать список**, укажите название и поля, затем сохраните настройки списка.
3. При необходимости задайте заголовок блока, сортировку, группировку и постоянный фильтр.
4. Сохраните блок. Опубликуйте исходную страницу, чтобы список стал доступен читателям.
5. На странице сайта нажмите **+ Запись** для добавления данных. Действия строки позволяют открыть, изменить или переместить запись в удалённые. В разделе **Удалённые** доступно восстановление.

Для повторного использования добавьте ещё один блок «Список» и выберите существующий список. Преобразование такого блока в глобальный не поддерживается. Копирование блока внутри сайта сохраняет ссылку на тот же набор данных.

Типы полей:

| Тип | Значение |
| --- | --- |
| Текст | До 2 000 символов |
| Многострочный текст | До 10 000 символов |
| Число | До 15 цифр до запятой и 6 после; хранение без потери десятичной точности |
| Дата | Календарная дата без времени |
| Выбор значения | Один вариант из настроенного списка |
| Да / нет | Флажок; снятый флажок означает «нет» |
| Сотрудник | Выбор активного пользователя портала по имени или логину |
| Ссылка / документ | HTTP(S) или локальная ссылка на документ; файл загружается через диск |

До 50 полей в списке, до 100 вариантов в поле выбора. Поля могут быть обязательными. Коды полей сохраняются при переименовании и перестановке. Сервер не разрешает удалить заполненное поле, изменить его тип или исключить используемый вариант выбора. Проверка учитывает удалённые записи. Для изменения таких полей сначала восстановите и исправьте соответствующие записи.

Таблица поддерживает поиск, фильтр по полю, сортировку, группировку и страницы по 25 записей. Группы могут продолжаться на следующей странице. Постоянный фильтр блока и фильтр посетителя применяются одновременно. Поле сотрудника ищется по сохранённому имени. Сортировка чисел выполняется численно.

## Права и сохранение

- Требуется авторизация на портале. Просмотр проверяет права и статус как текущей страницы, так и исходной страницы списка.
- Для изменения полей, записей и восстановления требуется право редактирования обеих страниц. Черновики доступны редакторам.
- Фильтр задаёт представление данных, а не отдельные права на строки. Отдельных прав на записи в первой версии нет.
- Смена списка в блоке не предоставляет доступ к чужому сайту или закрытой исходной странице. Если исходная страница удалена, набор данных недоступен до восстановления страницы.
- Изменения проверяются по версии записи и версии полей. При конфликте форма сохраняет введённый текст. Скопируйте необходимые изменения перед обновлением страницы.
- Удаление записи обратимо. Удаление блока не удаляет общий набор данных. Отдельного окончательного удаления набора данных в этой версии нет.

API принимает JSON через POST в `lists_api.php`, проверяет CSRF-токен и возвращает ответы с `Cache-Control: private, no-store`. Изменение схемы блокирует конкурентные изменения записей на время проверки; строки имеют отдельную блокировку при записи. Ключ повторного запроса предотвращает дублирование при повторной отправке одной формы добавления.

## Резервные копии и шаблоны сайтов

Снимок сайта включает каждый набор данных один раз, включая его удалённые записи. Восстановление создаёт новые идентификаторы списков и перенастраивает ссылки блоков. Старые снимки без списков остаются совместимыми.

Ссылки на документы сохраняются как URL; содержимое файлов этим механизмом не копируется. Сотрудники сохраняют идентификаторы и подписи текущего портала, включая бывших сотрудников. Переназначение пользователей между разными порталами не предусмотрено. История версий записей отдельно не хранится; версия используется для защиты от конфликтов.

## Проверки

```bash
php tests/data_lists_test.php
python3 tests/data_lists_http_test.py
node tests/data_lists_ui_test.js
```

Нужны PHP 8.1+ с mbstring, Python 3 с SQLite JSON и Node.js. `PHP_COMMAND` позволяет выбрать PHP для HTTP-тестов. Тесты выполняют настоящий сервис, API и JavaScript с изолированными адаптерами Битрикса, БД и DOM. SQL-тесты используют SQLite с переводом JSONB-приведений и удалением суффиксов блокировки; они не подтверждают поведение блокировок PostgreSQL или внешний вид в браузере.

После развёртывания на тестовом портале проверьте создание списка, выбор сотрудника, сохранение и восстановление записи, доступ читателя и конфликт двух открытых форм. Сам портал в локальной проверке не использовался.
